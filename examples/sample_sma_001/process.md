使用模型：自研参数化建模内核（通用建模器：cadlib = trimesh 几何 + Shapely 二维轮廓 + manifold3d 严格布尔）
主要改进：题干尺寸约束直接写入参数化程序；免支撑优先（朝下面一律 <=45 度斜面）；严格布尔保证水密单连通；活动件以 0.4mm 分层平行间隙实现打印就位
生成参数：全参数化，无随机采样

后处理流程：布尔残渣剔除 -> 退化面/重复面清理 -> 法向统一 -> 顶点按位置合并 -> 底面贴床（Z=0）与 XY 居中 -> 尺寸量级夹取到 [2,300]mm
失败样例与修正：初版以包围盒对角线判定回转体直径，把「外径约 90」的圆筒误判为 138mm，已改为取 XY 包络最大边；贴平台底面曾被计入悬垂面积，已剔除；布尔交界处重复顶点会让 split() 误判多连通体，已加 merge_vertices 修正
是否使用商业API：否（不使用任何神经网络，无模型权重，纯 CPU 离线运行）
数据来源说明：仅使用主办方公开的开发集/测试集 prompt；建模内核所用 trimesh / Shapely / manifold3d / numpy 均为开源库，未使用任何外部 3D 数据集
